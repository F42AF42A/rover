# Путь к универу — Rover

Браузерная 3D-игра про ровера-доставщика в Иннополисе. Собирайте кубы с верными ответами и объезжайте неверные.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:4173`.

## Файлы

- `dist/index.html` — весь код игры: сцена, интерфейс, задачи, управление и звук.
- `package.json` и `package-lock.json` — локальный сервер Vite.

Для статического хостинга используйте папку `dist`; сборка не требуется. HTML оставлен без внешних обёрток для совместимости с артефактами. Для загрузки Three.js и Google Fonts нужен интернет. Геометрия, текстуры и звук создаются программно; внешних 3D-моделей нет.

## Управление и правила

- На телефоне: свайп или тап по левой/правой половине экрана.
- На компьютере: стрелки или A / D. Пробел начинает новый заезд.
- 12 задач: сначала сложение и вычитание до 10, затем до 20, в конце простое умножение и деление на 2–3.
- Каждый заезд получает новые числа и расположение кубов.
- Верные ответы повышают скорость. Три столкновения с неверными кубами приводят к поломке и остановке с дымом.
- Три звёздочки показывают оставшиеся попытки.
- Кнопка ♪ / ♫ включает и выключает городской фон, птиц, мотор и звуки ответов.

## Технологии и проверки

Three.js r128 с резервным CDN r156, Web Audio, процедурные модели, InstancedMesh. Лучший результат хранится локально в браузере.

Программно проверены генерация и арифметика задач, полный успешный заезд, поломка после третьей ошибки, остановка, дым и повторный старт. Визуальная проверка и FPS на реальных мобильных устройствах пока не подтверждены.
